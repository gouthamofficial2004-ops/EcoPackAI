# EcoPackAI – AI-Powered Sustainable Packaging Recommendation System

## Project Overview

EcoPackAI is an AI-powered sustainable packaging recommendation system designed to help businesses identify suitable packaging materials based on product requirements, cost, durability, and environmental impact.

## Objectives

- Recommend suitable sustainable packaging materials.
- Estimate packaging cost.
- Predict CO₂ emissions.
- Evaluate material sustainability.
- Compare packaging alternatives.

## Technology Stack

- Python
- Pandas and NumPy
- Scikit-learn
- XGBoost
- Flask
- PostgreSQL
- HTML, CSS, Bootstrap and JavaScript
- Plotly

## Project Modules

1. Data Collection and Management
2. Data Cleaning and Feature Engineering
3. ML Dataset Preparation
4. AI Recommendation Model
5. Flask Backend API
6. Frontend User Interface
7. Business Intelligence Dashboard
8. Deployment and Documentation
